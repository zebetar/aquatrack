# **App Name**: AquaTrack Mobile

## Core Features:

- User Authentication: Login for Admins and Viewers with role-based dashboard navigation.
- Role-Based Dashboards: Mobile-optimized dashboards with key metrics (Admin) and summaries (Viewer).
- Water Usage Logging: Input customer water usage details with cost calculation.
- Customer Management: Manage customer information, including usage and billing history.
- Payment Recording: Record customer payments and update balances.
- Reporting: Generate monthly reports with summary statistics.
- Push Notifications: Notify users by push notification of certain events, like water use or payment that was recorded by the admin.

## Style Guidelines:

- Primary color: Muted blue (#6495ED), offering a modern and calming feel, fitting for resource management.
- Background color: Light gray (#F0F0F0), providing a neutral backdrop for content.
- Accent color: Pale Blue (#ADD8E6) for interactive elements and highlights to improve visibility and usability.
- Clear, standard mobile-native fonts for readability across devices.
- Simple, minimalist icons to represent water usage, payments, and notifications.
- Tab bar navigation for primary sections and list views for data presentation.
- Subtle animations on data updates and transitions.
